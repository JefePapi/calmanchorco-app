Shop Automation Suite — Internal Listing Management Tool

About This Application

The CalmAnchorCo Automation Suite is a private, internal tool used exclusively by the owner of the CalmAnchorCo Etsy shop to manage and publish digital product listings.

This application uses the Etsy API v3 to automate the creation and management of listings within a single Etsy shop. It does not collect, resell, or share any data. It does not interact with any Etsy shop other than the one it is authorised by.

Data accessed: Listing data, shop metadata, and taxonomy references — all belonging to the authorising shop owner only.

No scraping. No bulk data collection. No third-party access.

Privacy Policy

Effective date: May 1, 2026

1. What data we collect
This application accesses Etsy API data solely on behalf of the authenticated shop owner. No personal data belonging to Etsy buyers, third-party sellers, or the public is collected, stored, or processed.

2. How data is used
OAuth tokens and shop identifiers are stored locally on the owner's device using Windows DPAPI (Data Protection API), an operating-system-level encryption mechanism. No data is transmitted to external servers.

3. Data sharing
We do not sell, share, rent, or transmit any data to third parties. This application has no server-side component and no external database.

4. Data retention
All credentials can be deleted at any time by the owner by removing the local encrypted credential file. Revoking the OAuth token in Etsy's developer portal immediately terminates all API access.

5. Cookies
This website does not use cookies or any tracking technology.

6. Contact
For any privacy-related questions, contact the shop owner via the CalmAnchorCo Etsy shop messaging system.
